# 骑行记录（喜德盛骑行 App 数据）

喜德盛骑行 App 的全部骑行记录，从云端拉下来转成 FIT，并生成一个本地展示页。

## 日常使用

| 做什么 | 怎么做 |
|---|---|
| 同步新骑行 | 先用 iTunes / Apple 设备备份一次 iPhone（不加密），然后 `uv run xds_sync.py` |
| 看展示页、改名 | 双击 `骑行记录.cmd`（本机 127.0.0.1:8770，改名写入 `rides/names.json`） |

登录凭证每次从最新的 iPhone 备份里读，只放在内存里，不落盘。提示「凭证失效」时，打开一次 App 再重新备份。

## 文件

| 路径 | 内容 |
|---|---|
| `rides/raw/<id>.bin` | 云端原始数据（FlatBuffers），**原样保留，不做任何修改** |
| `rides/all/*.fit` | 每次骑行一个 FIT，由 raw 生成（应用了下面的修正） |
| `rides/rides_index.json` | 云端骑行列表（云端原值） |
| `rides/corrections.json` | 码表时钟错误的时间修正（如 3/26 那条实为 4/2） |
| `rides/names.json` | 骑行名称：自动地名 + 手动改名；以「上班通勤 / 下班通勤」开头的算作通勤 |
| `rides/hr_quality.json` | **心率带数据质量**，见下 |
| `rides/segments.json` | 路段定义，见下 |
| `rides/dashboard.html` | 展示页（每次同步自动重新生成） |

## 体能趋势（展示页「趋势」）

骑车主要是上下班通勤，时间固定（上班约 56 分钟，9:30 前到；下班约 60 分钟，18:00 前到），所以指标都从正常通勤里自动算，
不需要专门测试。上下班地形不同（下班爬升约是上班的两倍），**上下班不放在一起比**。每次同步自动重算。

| 区块 | 指标 | 算法 |
|---|---|---|
| 心肺 | 同功率心率 | 每趟通勤去掉前 10 分钟，平均心率按 0.27 bpm/W 换算到 100 W（0.27 来自「心率 ~ 功率 + 训练量」的回归） |
| 心肺 | 红灯心率恢复 | 骑到 ≥140 bpm 遇红灯、停 45–75 秒（约 1 分钟；停得越久降得越多，所以只比这个区间），停前最后一个心率减去起步第一个心率（App 停车时不记录），每次骑行取中位数 |
| 心肺 | 出门爬坡：同功率坡顶心率 | 「出门爬坡」路段最后 20 秒心率，按 0.27 bpm/W 换算到 105 W |
| 力量 | 丈八东路功率 | 每次通过的平均功率，≥160 W 标为强度日 |
| 力量 | 每月最佳 1 / 5 分钟功率 | 当月所有骑行里最高的滑动平均（停车算 0 W），不是全力测试，是下限 |
| 训练量 | 每周骑行时长、训练量 | 训练量 = 每天做功（kJ）的 42 天指数加权平均 |
| 参考 | 通勤速度 / 平均功率 | 上下班分开 |

**分析结论（2026-10）**：体能跟着训练量走，不是一直往上涨。7–8 月天热不骑通勤，训练量从 6 月的约 136 掉到约 57，
同功率心率、红灯恢复、路段用时都明显变差；9 月恢复后 3–4 周基本回来。保持每周骑行、避免停骑两周以上是最重要的。
心率存疑的骑行（`rides/hr_quality.json`）不参与任何心率指标。

## ⚠ 心率数据质量 —— 做任何心率分析前先看这里

心率带有时接触不良（2026-10 天凉后出现：10/8 早晚、10/13 早）。`xds_hrq.py` 会逐秒找出不可能是真实心率的点：
掉线、掉线前卡住的数值、没发力却 10 秒内骤升 ≥25 bpm、骤降 ≥25 bpm、一分钟内反复断连且数值跳变、
超过合理上限（`ceiling`，默认 180）、刚出发电极未湿时的偏高读数。

- 这些点在 **FIT 文件和展示页里都已去掉**（该秒没有心率），平均 / 最高心率只用剩下的数据计算。
- `rides/hr_quality.json` 的 `rides` 列出每次受影响骑行的状态、去掉的比例、原因、去掉的路段（km）。
  - `suspect`：心率整体不可靠。**做心率趋势、心率与功率关系等分析时，整次排除这些骑行**，不要只用剩下的点。
  - `minor`：只有零星掉线，剩下的数据可正常使用。
- 手动覆盖写在同一文件的 `manual`：`"<骑行 id>": "bad"` 整次丢弃心率，`"ok"` 不做处理；改完重新运行 `xds_sync.py`。
- 原始心率仍保存在 `rides/raw/*.bin` 里，需要时可以重新判断。
